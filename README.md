# Trayecto

Demostración de Trayecto, el sistema de seguimiento de trayectorias escolares de MR Digital, preparada para la Escuela Técnica Carmen Molina de Llano (Corrientes).

- `demo.html`: la demostración (asistencia, calificaciones, semáforo de riesgo, avisos automáticos a las familias e informes). Usa datos ficticios.
- `og.png`: imagen de vista previa para compartir el enlace.
- `vercel.json`: direcciones limpias (`/demo`) y redirección de la raíz a la landing publicada.

Publicación: cada cambio en la rama `main` se publica automáticamente en Vercel.

Dirección de la demo: `/demo` (por ejemplo, https://trayecto.misterdigital.org/demo).
